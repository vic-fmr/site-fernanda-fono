# Fernanda Fono

Site institucional da Fernanda Fono, desenvolvido com Next.js, React, TypeScript e Tailwind CSS.

## Desenvolvimento local

Requisitos: Node.js 20 ou superior.

```bash
npm install
npm run dev
```

O site ficará disponível em [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev`: inicia o servidor de desenvolvimento.
- `npm run build`: gera a versão de produção.
- `npm run start`: inicia a aplicação em produção.
- `npm run lint`: executa o ESLint.

## Rotas

- `/`: página inicial.
- `/especialidades`: especialidades e serviços.
- `/como-funciona`: metodologia de atendimento.
- `/sobre`: apresentação profissional.
- `/duvidas`: perguntas frequentes.
- `/contato`: informações de contato.

## Deploy

O projeto está configurado para deploy na Vercel a partir da branch `main`. Cada atualização enviada ao GitHub pode gerar um novo deploy automaticamente.
